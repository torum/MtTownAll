# MtTownAll

A GUI applicaton for converting **"mt_town_all.csv"** file from the Digital Agency of Japan's [base registry for address](https://www.digital.go.jp/en/policies/base_registry_address) into a SQLite database.  

デジタル庁が[公開](https://www.digital.go.jp/policies/base_registry_address)している「全国 町字マスター」**"mt_town_all.csv"** を扱いやすいSQLiteデータベースファイルに変換するGUIアプリケーションのコンバーター。

補足：[zipcloud](https://zipcloud.ibsnet.co.jp/)さんの「郵便番号データ」（x-ken-all.csv）と、[駅データ.jp](https://ekidata.jp/) さんの「路線データ」（lineyyyymmddfree.csv）、「駅データ」（stationyyyymmddfree.csv）の変換にも対応。
