# MtTownAll

A simple GUI application for converting **"mt_town_all.csv"** file from the Digital Agency of Japan's [base registry for address](https://www.digital.go.jp/en/policies/base_registry_address) into a SQLite database. Additionally it also supports "mt_pref_all.csv", "x-ken-all.csv", "lineyyyymmddfree.csv", "stationyyyymmddfree.csv" and "abr_post_code.csv".

デジタル庁が公開している「[全国 町字マスター](https://www.digital.go.jp/policies/base_registry_address)」**"mt_town_all.csv"** を扱いやすいSQLiteデータベースファイルに変換するGUIアプリケーションのコンバーター。

ついでに、[zipcloud](https://zipcloud.ibsnet.co.jp/)さんの「郵便番号データ」（x-ken-all.csv）と、[駅データ.jp](https://ekidata.jp/) さんの「路線データ」（lineyyyymmddfree.csv）、「駅データ」（stationyyyymmddfree.csv）の変換にも対応。

さらについでに、「[ABR町字・郵便番号変換表](https://dataset.address-br.digital.go.jp/datasets/1098a4f61dab4f52997839d04245132a/about)」（abr_post_code.csv）の変換にも対応。
